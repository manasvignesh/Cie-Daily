# Project Catalyst

Project Catalyst is a highly curated, private social learning platform exclusively designed for the students of MLRIT.

Currently in **v0.9.0-beta**.

## Structure
- `/app` - Flutter Mobile Application (Student App)
- `/admin` - Next.js Admin Dashboard (Content Management)
- `/supabase` - Database migrations and backend configuration
- `/docs` - Comprehensive project documentation

## Quick Start

### Admin Portal
```bash
cd admin
npm install
npm run dev
```

### Mobile App
```bash
cd app
flutter pub get
flutter run
```

Please refer to the `/docs` directory for complete instructions on architecture, API schema, and deployment.
