# Admin Guide

Welcome to the Catalyst Admin Portal.

1. **Dashboard**: View high-level metrics (DAU, WAU).
2. **Posts & Drops**: Create highly curated articles using the Notion-style Block Editor.
3. **Live Spaces**: Trigger WebRTC rooms. You can mute participants and manage raise-hands here.
4. **Users**: View the CRM of all students on the platform.
5. **Notifications**: Push manual FCM notifications to specific cohorts (e.g., just the CSE department).
