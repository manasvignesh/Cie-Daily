# Engineering Constitution

1. **Mobile-First**: The client app is built primarily for Android/iOS.
2. **Performance-First**: Smooth 60fps scrolling. Launch under 2 seconds. Images load under 1 second. 
3. **Offline-First**: Hive/Isar is used for caching so the app works on spotty college Wi-Fi.
4. **Realtime**: Supabase streams are used instead of polling.
