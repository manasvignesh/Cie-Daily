# Product Documentation

## Vision
Curiosity is the product. Learning becomes the side effect. 
Project Catalyst is designed to build a habit of intellectual curiosity among college students.

## Core Principles
1. **Habit-Forming**: Success is measured by retention (DAU/WAU), not installs.
2. **Curated Drops**: Information is high-signal, low-noise. 
3. **Live Engagement**: Spaces bring real-time human connection back into the learning experience.

## Features
- **The Feed**: Algorithmic, infinite-scroll vertical feed of high-quality articles.
- **Spaces**: Live audio/video rooms with screen sharing.
- **Social**: 1-to-1 messaging, group chats, and feed-sharing.
- **Admin Portal**: Fully customized dashboard for content moderation.

## User Flow
- Login with Email -> Receive OTP -> Setup Profile -> Land on Feed.
- Navigate to Spaces -> Join active audio room.
- Navigate to Inbox -> Message peers.
