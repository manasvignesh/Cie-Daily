# Closed Beta Release Checklist

### Pre-Flight
- [ ] 20-30 students onboarded manually.
- [ ] Mix of 1st-year and senior students.
- [ ] Sentry / Crashlytics environment verified.
- [ ] 100+ Curated posts seeded.
- [ ] 5-10 upcoming Spaces scheduled.

### Success Metrics
- [ ] DAU / WAU analysis.
- [ ] Session duration > 5 minutes.
- [ ] Number of posts viewed per session > 10.
- [ ] Space joining rate > 20% of DAU.
